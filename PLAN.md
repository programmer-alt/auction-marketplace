## Этап 3: Backend — API (Дни 6-14)

### 3.1. Базовая структура сервера
- [ ] Создать `src/index.ts` — точка входа Express
- [ ] Настроить CORS и middleware
- [ ] Настроить подключение к PostgreSQL и Redis

### 3.2. Аутентификация
- [ ] Создать `src/routes/auth.ts`
- [ ] Реализовать `POST /api/auth/register`:
  - Валидация через Zod
  - Хеширование пароля (bcrypt)
  - Сохранение в БД
- [ ] Реализовать `POST /api/auth/login`:
  - Проверка пароля
  - Генерация JWT токена
- [ ] Реализовать `GET /api/auth/me`:
  - Middleware проверки JWT
  - Возврат данных пользователя
- [ ] Создать middleware `authMiddleware.ts`

### 3.3. Аукционы
- [ ] Создать `src/routes/auctions.ts`
- [ ] Реализовать `GET /api/auctions`:
  - Список всех активных аукционов
  - Пагинация и фильтры
- [ ] Реализовать `GET /api/auctions/:id`:
  - Детали аукциона + текущие ставки
- [ ] Реализовать `POST /api/auctions`:
  - Создание лота (только авторизованный продавец)
  - Валидация данных
- [ ] Реализовать `PUT /api/auctions/:id`:
  - Обновление лота
- [ ] Реализовать `DELETE /api/auctions/:id`:
  - Удаление лота

### 3.4. Ставки
- [ ] Создать `src/routes/bids.ts`
- [ ] Реализовать `POST /api/auctions/:id/bids`:
  - Проверка, что аукцион активен
  - Проверка, что ставка выше текущей
  - Сохранение в БД
- [ ] Реализовать `GET /api/auctions/:id/bids`:
  - История ставок по аукциону

### 3.5. Платежи
- [ ] Создать `src/routes/payments.ts`
- [ ] Настроить Stripe SDK
- [ ] Реализовать `POST /api/payments/create-intent`:
  - Создание Payment Intent Stripe
- [ ] Реализовать `POST /api/webhooks/stripe`:
  - Обработка webhook от Stripe
  - Обновление статуса платежа
- [ ] Реализовать `GET /api/payments/history`:
  - История платежей пользователя

### 3.6. WebSocket (Socket.io)
- [ ] Настроить Socket.io сервер в `src/index.ts`
- [ ] Реализовать real-time уведомления о новых ставках
- [ ] Реализовать события:
  - `bid:new` — новая ставка
  - `auction:ended` — аукцион завершён
  - `auction:updated` — обновление аукциона

### 3.7. Redis Integration
- [ ] Установить и настроить Redis клиент (`ioredis` или `redis`)
- [ ] Настроить Socket.io адаптер Redis для масштабирования
- [ ] Реализовать кэширование часто запрашиваемых данных (список аукционов)
- [ ] Настроить очередь задач (Bull) для отложенных операций (завершение аукционов, отправка email)
- [ ] Добавить rate limiting middleware с использованием Redis
