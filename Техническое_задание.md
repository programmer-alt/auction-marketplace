# Техническое задание: Auction Marketplace

**Проект:** Auction Marketplace  
**Роль:** Full-Stack Developer  
**Дата:** 2026

---

## 1. Цель проекта

Создать платформу для проведения аукционов с возможностью:
- Размещения лотов продавцами
- Размещения ставок покупателями
- Оплаты через Stripe
- Просмотра истории транзакций

## 3. Структура базы данных (Prisma Schema)

```prisma
model User {
  id        Int       @id @default(autoincrement())
  email     String    @unique
  password  String
  name      String?
  balance   Decimal   @default(0) @db.Decimal(10, 2)
  auctions  Auction[] @relation("SellerAuctions")
  bids      Bid[]
  payments  Payment[]
  createdAt DateTime  @default(now())
}

model Auction {
  id           Int        @id @default(autoincrement())
  title        String
  description  String?
  imageUrl     String?
  startingPrice Decimal    @db.Decimal(10, 2)
  currentPrice Decimal    @db.Decimal(10, 2)
  sellerId     Int
  seller       User       @relation("SellerAuctions", fields: [sellerId], references: [id])
  winnerId     Int?
  winner       User?      @relation("WinnerAuctions", fields: [winnerId], references: [id])
  status       AuctionStatus @default(ACTIVE)
  endsAt       DateTime
  bids         Bid[]
  payments     Payment[]
  createdAt    DateTime   @default(now())
}

model Bid {
  id        Int      @id @default(autoincrement())
  auctionId Int
  auction   Auction  @relation(fields: [auctionId], references: [id])
  userId    Int
  user      User     @relation(fields: [userId], references: [id])
  amount    Decimal  @db.Decimal(10, 2)
  createdAt DateTime @default(now())
}

model Payment {
  id              Int            @id @default(autoincrement())
  userId          Int
  user            User           @relation(fields: [userId], references: [id])
  auctionId       Int
  auction         Auction        @relation(fields: [auctionId], references: [id])
  amount          Decimal        @db.Decimal(10, 2)
  stripePaymentId String?
  status          PaymentStatus  @default(PENDING)
  createdAt       DateTime       @default(now())
}

enum AuctionStatus {
  ACTIVE
  COMPLETED
  CANCELLED
}

enum PaymentStatus {
  PENDING
  COMPLETED
  FAILED
}
```

## 4. API Endpoints

### Аутентификация
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход
- `GET /api/auth/me` - Текущий пользователь

### Аукционы
- `GET /api/auctions` - Список аукционов
- `GET /api/auctions/:id` - Детали аукциона
- `POST /api/auctions` - Создать аукцион (продавец)
- `PUT /api/auctions/:id` - Обновить аукцион
- `DELETE /api/auctions/:id` - Удалить аукцион

### Ставки
- `POST /api/auctions/:id/bids` - Сделать ставку
- `GET /api/auctions/:id/bids` - История ставок

### Платежи
- `POST /api/payments/create-intent` - Создать платеж
- `POST /api/webhooks/stripe` - Webhook Stripe
- `GET /api/payments/history` - История платежей

---

## 5. Основные функции

1. **Регистрация/Вход** - JWT токены
2. **Создание лота** - Заполнение формы с названием, описанием, ценой, фото
3. **Просмотр лотов** - Список с фильтрами и поиском
4. **Размещение ставок** - Real-time обновление через WebSocket
5. **Завершение аукциона** - Автоматически по времени
6. **Оплата** - Stripe Checkout
7. **История** - Мои аукционы, мои ставки, платежи

## 7. Почему эти технологии?

### Prisma
- Type-safe запросы к БД
- Автоматические миграции
- Простая схема данных
- Отличная документация

### Tailwind CSS
- Быстрая стилізація
- Не нужно писать CSS файлы
- Современный вид "из коробки"

### Zod
- Валидация на фронтенде и бэкенде
- TypeScript совместимость
- Понятные ошибки

### Socket.io
- Real-time ставки
- Уведомления о новых ставках
- Простой API
